StackQueueValley is a Java based farming and adventure RPG game inspired by Stardew Valley. 

The project began with my individual implementation, which was subsequently adopted as the foundation for further development by my project team. 

## KEY CONTRIBUTION
* Core Game Development: Developed the initial game implementation, including farming mechanics and player interaction

* Farming System: Implemented crop-specific watering, harvesting, and consumption mechanics.

* Creature AI: Developed state based healing behaviour for hostile creatures

* Quest System: Designed and implemented timed quests, objectives, rewards, player progression, and dice-wager mechanics.

* Weather Response System: Developed a modular weather-response subsystem supporting terrain drainage, livestock shelter, and resource recovery using interfaces and polymorphism.

* Code Refactoring & Maintenance: Contributed to debugging, integration, and maintenance of the shared codebase. Ensure reusable abstractions to reduce code duplication and improve maintainability and extensibility.
